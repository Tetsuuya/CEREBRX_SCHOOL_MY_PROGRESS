PROBLEM:
--------
Generated Excel files had hidden rows only preserved in TERM1 sheet.
Other sheets (INPUT, TERM2, TERM3, SUMMARY OF GRADES) lost hidden rows.

Analysis of generated file (TLE 7-Grade 7 CS3A-20260625022037.xlsx):

  TERM2:              Expected: 12,63,65,116    →  Actual: 116          (LOST: 12,63,65)
  TERM3:              Expected: 12,63,65,116    →  Actual: 116          (LOST: 12,63,65)
  SUMMARY OF GRADES:  Expected: 13,64,66,117    →  Actual: 117          (LOST: 13,64,66)

ROOT CAUSE:
-----------
PHPExcel-1.8 has a CRITICAL BUG: The save() method doesn't reliably write
hidden="1" attribute to XML even after calling both setVisible(false) and 
setRowHeight().

We tried fixing it by:
1. ❌ Phase 1: Detecting hidden rows before data insertion
2. ❌ Phase 2: Re-hiding rows after data insertion
3. ❌ Phase 3: Final pass to re-apply hidden rows + setRowHeight()

Result: Logs show "Re-set height to 18" but XML still missing hidden="1"

This means PHPExcel has a deeper bug in its XML writer that cannot be fixed
at the PHP API level.

FINAL SOLUTION - XML POST-PROCESSING:
--------------------------------------
Since PHPExcel cannot be trusted, we now POST-PROCESS the saved file:

1. PHPExcel saves the Excel file (ZIP archive)
2. Extract the ZIP to temp directory
3. Read each sheet's XML file (xl/worksheets/sheet1.xml, sheet2.xml, etc.)
4. Manually inject hidden="1" attribute into <row> elements
5. Re-zip the modified files back into Excel format
6. Clean up temp directory

This bypasses PHPExcel's buggy XML writer entirely.
