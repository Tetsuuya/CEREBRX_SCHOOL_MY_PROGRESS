================================================================================
TECHNICAL NOTES
================================================================================

WHY XML POST-PROCESSING IS STILL NEEDED:
- PHPExcel has a bug where it doesn't write hidden="1" attribute to XML
- This happens during save(), even for sheets we never touch
- Direct XML manipulation is the only reliable fix
- We can't skip XML post-processing, but we CAN skip Phases 1 & 3

WHY WE ONLY POPULATE INPUT SHEET:
- Template has formulas in TERM1/2/3 that reference INPUT
- Example: TERM1!C14 = =INPUT!B12
- If we write to TERM1!C14, we destroy the formula
- By only writing to INPUT, formulas remain intact
- Excel automatically recalculates formulas when file opens
