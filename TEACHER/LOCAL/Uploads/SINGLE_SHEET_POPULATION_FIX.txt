THE PROBLEM:
================================================================================

BEFORE THIS FIX:

- PHP populated student names in ALL 5 sheets
- This OVERWROTE 1,671 formulas in TERM1/TERM2/TERM3/SUMMARY

- INPUT sheet: Empty cells where PHP fills student names
- TERM1/TERM2/TERM3/SUMMARY: Formulas like =INPUT!B12 that automatically reference INPUT

When PHP populated all sheets, it destroyed this formula-based design.
