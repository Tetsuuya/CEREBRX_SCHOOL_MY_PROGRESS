TEMPLATE STRUCTURE:
================================================================================

The template has 9 sheets:
1. INPUT (sheet1.xml) - Main data entry sheet
2. TERM1 (sheet2.xml) - References INPUT via formulas
3. TERM2 (sheet3.xml) - References INPUT via formulas
4. TERM3 (sheet4.xml) - References INPUT via formulas
5. SUMMARY OF GRADES (sheet5.xml) - References INPUT via formulas
6. FINAL (sheet6.xml)
7. REMEDIAL (sheet7.xml)
8. Helper (Do Not Delete) - Hidden
9. DO NOT DELETE - Hidden

================================================================================
HOW THE TEMPLATE WORKS:
================================================================================

INPUT SHEET (Main Data Entry):
-------------------------------
Row 11:  {start_boys_numbering} | {start_boys} | (header row)
Row 12:  EMPTY                  | EMPTY        | ← PHP fills boy #1 name here
Row 13:  EMPTY                  | EMPTY        | ← PHP fills boy #2 name here
...
Row 60:  EMPTY                  | EMPTY        | ← PHP fills boy #49 name here
Row 61:  {end_boys_numbering}   | {end_boys}   | (end marker)
Row 63:  {start_girls_numbering}| {start_girls}| (header row)
Row 64:  EMPTY                  | EMPTY        | ← PHP fills girl #1 name here
...
Row 111: EMPTY                  | EMPTY        | ← PHP fills girl #49 name here
Row 112: {end_girls_numbering}  | {end_girls}  | (end marker)

TERM1/TERM2/TERM3 SHEETS (Auto-Calculated):
-------------------------------------------
Row 12:  {start_boys_numbering} | {boys_start_id} | {start_boys} | {ww} | ... (header row with placeholders)
Row 13:  EMPTY                  | EMPTY           | EMPTY        | EMPTY| ... (separator/spacing row)
Row 14:  EMPTY                  | EMPTY           | =INPUT!B12   | ...  | ← FORMULA references INPUT row 12 (boy #1)
Row 15:  EMPTY                  | EMPTY           | =INPUT!B13   | ...  | ← FORMULA references INPUT row 13 (boy #2)
Row 16:  EMPTY                  | EMPTY           | =INPUT!B14   | ...  | ← FORMULA references INPUT row 14 (boy #3)
...

Total formulas in TERM1: 1,671 formulas
Sample formulas: =INPUT!B12, =INPUT!G4, =INPUT!L4, etc.

================================================================================
THE BUG IN CURRENT PHP IMPLEMENTATION:
================================================================================

WHAT THE CODE DOES NOW (WRONG):
1. Scans INPUT sheet, finds {start_boys} at B11
2. Populates INPUT B12, B13, B14... with student names ✓ CORRECT

3. Scans TERM1 sheet, finds {start_boys} at C12
4. Populates TERM1 C14, C15, C16... with student names ✗ BUG!
   - This OVERWRITES the formulas =INPUT!B12, =INPUT!B13, etc.
   - Template designer created these formulas intentionally
   - Now TERM1 has static text instead of dynamic formulas

5. Repeats step 3-4 for TERM2, TERM3, SUMMARY ✗ BUG!

THE RESULT:
- INPUT sheet: ✓ Correctly filled
- TERM1/TERM2/TERM3: ✗ Formulas destroyed, replaced with static text
- File size bloat: All sheets have duplicate data (increases file size)
- Loss of template functionality: Formulas are gone forever

================================================================================
THE CORRECT IMPLEMENTATION:
================================================================================

WHAT THE CODE SHOULD DO:
1. Scan INPUT sheet, find {start_boys} at B11
2. Populate INPUT B12, B13, B14... with student names ✓ CORRECT

3. Scan TERM1/TERM2/TERM3/SUMMARY sheets
4. SKIP THESE SHEETS - do NOT populate student data
   - The formulas =INPUT!B12, =INPUT!B13 will automatically pull data
   - No need to touch these sheets at all

5. Optionally: Replace other placeholders in TERM1/TERM2/TERM3
   - {school_name}, {class}, {subject_name}, etc. can still be replaced
   - But do NOT populate student rows (preserve formulas)

THE RESULT:
- INPUT sheet: ✓ Filled with student data
- TERM1/TERM2/TERM3: ✓ Formulas intact, automatically show INPUT data
- Smaller file size: No duplicate data
- Template design preserved: Formulas work as intended

================================================================================
RECOMMENDATION:
================================================================================

OPTION A: SIMPLE FIX (Recommended)
---------------------------------
Modify generate_spreadsheet() to ONLY populate sheet index 0 (INPUT).
Skip all other sheets entirely.

PROS:
- Simple, clean, fast
- Preserves all formulas
- Smaller file size
- Respects template designer's intent

CONS:
- Placeholders like {school_name} in TERM1/TERM2/TERM3 won't be replaced
  (But they might already have formulas referencing INPUT, so this is fine)

OPTION B: SELECTIVE POPULATION
-------------------------------
Modify generate_spreadsheet() to:
1. Populate INPUT sheet fully
2. In TERM1/TERM2/TERM3/SUMMARY:
   - Replace metadata placeholders ({school_name}, {class}, etc.)
   - SKIP student data placeholders ({start_boys}, {start_girls})
   - Preserve all formulas

PROS:
- Fills all metadata
- Preserves formulas

CONS:
- More complex logic
- Need to identify which placeholders are "safe" to replace

OPTION C: KEEP CURRENT (Not Recommended)
-----------------------------------------
Keep populating all sheets with student data.

PROS:
- Works even if formulas are missing/broken
- Each sheet is independent

CONS:
- Destroys template formulas
- Larger file size (duplicate data)
- Goes against template design

================================================================================
CONCLUSION:
================================================================================

The user's intuition was CORRECT:

  "all the brackets in input are also in term1,2,3 and summary of grades too,
   so I think it makes sense to just only put in sheet 0? then just reference
   all the other tabs"

YES - we should only populate INPUT (sheet 0) and let TERM1/TERM2/TERM3/SUMMARY
reference it via their existing formulas.

The current multi-sheet population approach is DESTROYING the template's
formula-based design.
